# mastria.github.io

Site pessoal publicado via [GitHub Pages](https://pages.github.com).

🌐 **Acesse em:** [https://mastria.github.io](https://mastria.github.io)

## Estrutura

| Arquivo | Descrição |
|---------|-----------|
| `index.html` | Página principal do site |
| `style.css` | Estilos da página |

## Como publicar

1. Acesse **Settings → Pages** no repositório.
2. Em **Source**, selecione a branch `main` e a pasta `/ (root)`.
3. Clique em **Save** — o site estará disponível em `https://mastria.github.io`.
